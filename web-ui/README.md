# Web UI

React web companion UI for RikkaHub Local — chat interface, settings, and tools.

Built with React Router 7, TypeScript, Tailwind CSS v4, and pnpm.

## Commands

```bash
pnpm install        # install deps
pnpm run dev        # dev server (http://localhost:5173)
pnpm run build      # production build
pnpm run typecheck  # type checking
pnpm run lint       # lint
pnpm run fmt        # format
```

## Stack

- **Framework:** React Router 7 (SSR)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 (via `@tailwindcss/vite`)
- **Icons:** Lucide React
- **State:** Zustand
- **Lint:** oxlint
- **Format:** oxfmt
